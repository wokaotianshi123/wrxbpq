# XBPQ 规则字段参考

适用于 TVBox/XBPQ 爬虫 JSON，行为对齐 guoapp3 项目 `native/core/provider_xbpq.go`。

---

## 一、字段表

### 站点与请求

| 字段 | 别名 | 说明 |
|---|---|---|
| `主页url` | `首页url`、`请求` | 站点首页。**必填**，缺它规则不被识别。可省略 scheme（自动补 `https://`） |
| `请求头` | `User-Agent`、`UA` | 自定义 UA。也可写完整请求头行，程序会剥出 UA 部分 |

### 分类与列表

| 字段 | 别名 | 说明 |
|---|---|---|
| `分类` | | `名称$ID#名称$ID`。支持子分类 `1--动作片$5`。多组用 `\|\|` 分隔 |
| `分类url` | `分类Url` | 占位符 `{cateId}`（分类 ID）、`{catePg}`（页码）、`{handurl}`、`{limit}` |
| `数组` | | 列表条目外层截取 pattern |
| `列表数组` / `搜索数组` | | 分类页 / 搜索页各自的条目 pattern，不写则用 `数组` |
| `二次截取` | `列表二次截取`、`搜索二次截取` | 先截出主体区域再找条目，避开导航栏同名标签 |
| `标题` | `列表标题` | 条目标题 |
| `链接` | `列表链接` | 条目详情链接 |
| `列表图片` / `搜索图片` | `图片`、`主图` | 封面。**注意**：分类非空时字段查找加「列表」前缀，封面显式写 `列表图片` 更稳 |
| `副标题` | `备注` | 角标文案（集数/评分） |

### 搜索

| 字段 | 别名 | 说明 |
|---|---|---|
| `搜索url` | `搜索Url` | 占位符 `{wd}`。POST 形态：`url;post;body` |

### 详情

| 字段 | 别名 | 说明 |
|---|---|---|
| `详情url` | `详情页url` | 占位符 `{id}`。不写则用列表链接还原 |
| `影片名称` | `name` | 详情页标题。**不要用 `标题`**——它是列表层语义 |
| `简介` | | 剧情简介 |
| `封面` | `图片` | 详情页封面 |
| `类型` | | 分类标签 |
| `导演` / `主演` | | |
| `状态` | `影片状态` | 更新状态 |

### 播放

| 字段 | 别名 | 说明 |
|---|---|---|
| `播放数组` | | 分集容器截取 pattern |
| `线路数组` | | **多线路站点必填**。循环截取每个线路容器，`$$$` 拼成多组。值通常与 `播放数组` 相同 |
| `播放列表` | | 分集分隔符，默认 `#` |
| `播放标题` / `播放链接` | | 分集条目的标题与链接截取 |
| `跳转播放链接` | | 播放页里直链的截取 pattern |

## 二、截取语法

### 基本形态

```
start&&end          取两串之间的内容
A&&B&&C&&D          两步链：先在 A、B 之间取，再在结果里取 C、D 之间
A&&                 从 A 之后取到末尾
&&B                 从头取到 B
P1||P2||P3          多组备选，依次尝试直到命中
<h*>&&</h           起始锚点通配符 *（一个字段只用一个，惰性匹配任意内容）
X+Y&&Z+W            + 拼接：含 && 的段是截取指令，其余段是字面量
"线路标题":"SVIP短剧"  不含 && 的字段值是「指定字符串」字面量（固定标题/图片）
```

**转义**：连接符 `$ # & * [ ]` 要表本义时用 `\` 转义。
例：截取 `href="?cat&token=5543tdd…"` 中的 `token=5543tdd…`，pattern 写 `href="?cat\&&&"`（`\&&` 吃掉分隔符 `&&`，余下一个 `&` 拼回字面）。

### 修饰符（写在 token 尾部方括号里）

| 修饰符 | 作用 |
|---|---|
| `[包含:x#y]` | 结果必须含 x 或 y |
| `[不包含:x#y]` | 结果不能含 x 或 y；也可填序号剔除（`[不包含:1#9-11]`） |
| `[替换:a>>b#c>>d]` | 依次替换，`#` 分隔多组；替换为「空」即删除 |
| `[含序号:n]` / `[序号:n]` | 取切分后的第 n 段 |
| `[排序:a>b>c]` | 按关键词优先级给条目排序（线路数组常用：`[排序:自建蓝光>腾腾>优优]`） |

**重要**：`[包含:]` 在 `数组`（走列表扫描）里会跳过不满足的条目继续找；
在 `标题`、`链接`（走单次截取）里，不满足就直接返回空——不会往后找下一个同名标签。

### json 模式（`j:` 前缀，笔记 item 7）

接口直接返回 JSON 时不用截取，字段值写 `j:路径`：

```
"二次截取": "j:data.list"          缩小范围（返回该节点的 JSON 文本）
"数组": "j:list"                   迭代数组元素（相对 二次截取 缩小后的范围）
"标题": "j:title"                  元素内取标量
"链接": "https://host/book/+j:shortId"   字面量 + j:取值 拼接
"跳转播放链接": "j:data.urls[0].cdnUrl"  下标取元素属性
```

- **下标从 0 开始**（与底层 fastjson JSONPath 一致；实测规则 `data.list[0]`、`data.urls[0]` 均如此。笔记「最小下标为 1」的表述与实现不符，以实测规则为准）。
- 数组下标形态：`[n]` 第 n 个、`[]` 全部、`[n,]` 跳过前 n 个。
- json 模式内的字面拼接段用单引号：`'/play/'+j:id+'-1-1.html'`。
- 纯点路径（如 `data.list[0].name`）也可不加 `j:` 前缀，源是 JSON 时同样生效。

### Base64（笔记 item 8）

```
"二次截取": "Base64"        整页是 Base64 编码：不截取、只解码
"链接": "Base64(a&&b)"      对截取结果 Base64 解码后使用
```

### `;;` 附加模式标记

规则里 URL / pattern 尾部的 `;;xx`（如 `;;m`、`;;mrcRAD`、`;;d0`）是 jar 的附加模式开关标记，
引擎解析 URL 时自动忽略。

### 选择器（`p:` / `jsoup:` 前缀）

```
p:div.box a.title[href]      后代选择器，取 href 属性
p:li.item                    取文本
p:ul.list li[包含:第]         带修饰符
```

语法：标签、`.类`、`#id`、`[attr=val]`、`[attr]`（表示取该属性值）；空格或 `>` 分隔层级。

## 三、播放串结构

```
线路1$$$线路2$$$线路3        $$$ 分线路
集1#集2#集3                  # 分集（可用「播放列表」改分隔符）
标题$链接                     $ 分隔标题与地址
```

- 取**集数最多的那条线路**作为主线路。
- 写了 `线路数组` 时，其余线路按集序号挂到每集上，播放时可切换。
- 标题不一致的线路整条跳过，避免集数不同导致错位。
- JS 里的 `\/` 转义会自动还原。

## 四、直链解析顺序

播放页按以下顺序尝试，第一个成功即用：

1. `跳转播放链接` 截取 → 若是 m3u8/mp4 直链直接用；若是二级播放页则再抓一次
2. `player_aaaa` / `player_data` 对象的 `url` 字段（按 `encrypt` 解密）
3. 页面正则兜底：`$.url="..."`、`"url":"...m3u8"`、裸 `https://...m3u8`

### 常见直链藏法

| 形态 | 说明 |
|---|---|
| `var player_aaaa={"url":"...","encrypt":0}` | MacCMS/macplus 最常见 |
| `player_data={...}` | 另一套播放器变量 |
| `new Artplayer({url: '...'})` | Artplayer |
| `url: 'https://.../index.m3u8'` | CKPlayer / DPlayer 配置 |
| 直接出现 `https://.../index.m3u8` | 裸直链，最好处理 |

**排查手法**：把播放页所有 `<script>` 内容打出来，搜 `url` / `.m3u8` / `.mp4` / `playurl`。

**坑**：`"url":"` 这种短锚点往往不唯一（页面里 `maccms` 配置也含它），
单次截取会先命中错误的那个。要么用更长的上下文，要么交给内置的 `player_aaaa` 解析。

## 五、占位符

| 占位符 | 出现位置 | 含义 |
|---|---|---|
| `{cateId}` | `分类url` | 分类 ID |
| `{catePg}` | `分类url` | 页码 |
| `{wd}` | `搜索url` | 搜索关键词（自动 URL 编码） |
| `{id}` | `详情url` | 影片 ID |

规则里写的域名与站源当前地址不一致时（镜像、换域名），**以站源地址为准重写 host**。
这只影响请求模板，不影响内容链接。

## 六、常见坑

| 现象 | 原因 | 对策 |
|---|---|---|
| 封面变成首页 URL | 懒加载占位 `data-original="/"` | 封面锚点带协议前缀：`data-original="https:&&"` |
| 取到一堆无关条目 | `数组` 命中了导航栏同名标签 | 加 `二次截取` 先限定主体区域 |
| 详情标题错乱 | 用了 `标题` 而非 `影片名称` | 详情层必须用 `影片名称` |
| 只有 1 条线路 | 未写 `线路数组` | 补上，值与 `播放数组` 相同 |
| 分集数是所有线路之和 | 用跨线路的大范围截取代替 `线路数组` | 必须用 `线路数组` |
| 分类 ID 被过滤 | 分类写成英文 slug | 已支持，照抄即可 |
| 翻页无变化 | 页码占位符位置不对 | 确认 `{catePg}` 在路径还是文件名 |
| end 锚点串味 | 用了 `&nbsp;` 之类会跨标签的边界 | 换成 `<span` 这类更近的边界 |
