# XBPQ 站点结构类型模板库

依据 **379 份 csp_XBPQ 真实规则**（TVBox 聚合配置）+ **18 份 XBPQ-main 官方样例** + **xbpq 写源自学笔记** 聚类归纳。
用途：拿到一个新站，先用首页/分类页 URL 与 HTML 特征**对号入座**到某家族，直接套用该家族的默认字段集，
再把与样本不符的字段改掉即可——这是「简写」能成立的原因（61% 的真实规则不写主页url，55% 只写分类url+分类）。

> 本文件与 `internal/xbpq/template.go`（及 guoapp3 `native/core/provider_xbpq_template.go`）一一对应：
> 文档是知识来源，代码是机器可读版；改文档不改代码，简写不会变聪明，反之亦然。

## 一、MacCMS `index.php/vod` 家族（58 份 ≈ 15%）

**指纹**：分类url 形如
`…/index.php/vod/type/id/{cateId}/page/{catePg}.html`（type 式，无筛选）或
`…/index.php/vod/show/area/{area}/by/{by}/class/{class}/id/{cateId}/page/{catePg}/year/{year}.html`（show 式，带筛选）；
首页源码含 `maccms` 字样；模板目录常为 `/template/stui…/`。

**要点**：
- show 式的**空筛选段必须省略**（`/area//` 直接 404）。jar 与本项目引擎都会自动剪掉空段（`rule.go cleanEmptySegments`）。
- MacCMS 自带 API：`/api.php/provide/vod/?ac=videolist`（或 `/inc/api.php/…`）。**能用 API 就别截 HTML**（§6）。
- 搜索三种形态都见过：`/index.php/vod/search.html?wd=`、`/index.php/vod/search/wd/{wd}.html`、`/search/{wd}----------{pg}---.html`（横线占位是 MacCMS 筛选位）。
- 播放列表页里 `player_aaaa` 与 `maccms` 配置并存，跳转直链用 `var player_*"url":"&&"` 锚（避开 `var maccms` 的 `"url":"`）。

**家族默认字段**（= template.go MacCMS 项）：
```
数组     class="stui-vodlist__thumb&&</a> || stui-vodlist__box">&&</div></div> || hl-item-thumb hl-lazy"&&</a> || module-poster-item&&</a> || <li&&</li>
标题     title="&&" || alt="&&"
图片     data-original="&&" || data-src="&&" || src="&&"
副标题   pic-text text-right">&&</span> || class="remark">&&< || module-item-text">&&</div>
链接     href="&&"
播放数组 <ul class="stui-content__playlist&&</ul> || id="hl-plays-list"&&</ul> || mod play-list&&</ul || class="play_box&&</div>
播放标题 >&&</a> || >&&<
跳转播放 var player_*"url":"&&
搜索url  {host}/index.php/vod/search.html?wd={wd}
```
注：MacCMS 家族横跨 stui / hl（海蓝）/ module（苹果cms新版）三套前端皮肤，`||` 备选链就是按皮肤优先级排的。

## 二、MacCMS myui 短路径家族（92 份 ≈ 24%）

**指纹**：`/vodtype/{cateId}/page/{catePg}.html`、`/vodshow/{cateId}-{area}-{by}------{catePg}---{year}.html`
（`-` 连串的横线段是可省略筛选位）。其余与 §1 完全同构（同一个 CMS，只是伪静态前缀不同）。

**要点**：
- `vodshow` dash 形态里**空筛选写空串保留占位横线**（`---1---`），与 §1 的路径式剪空段不同——引擎的剪段逻辑只处理路径式 `/area//`，dash 形态天然允许空。
- 详情链接转播放链接的经典简写：`"链接": "href=\"&&\"[替换:voddetail>>vodplay#.html>>-1-1.html]"`（6 处实战）——省掉详情页直接给播放页。

## 三、conch/ dash 式家族（12 份，如 厂长资源、午舞影视）

**指纹**：`/{cateId}/{class}/{area}/page/{catePg}`、`/show/{cateId}-{area}-{by}------{catePg}---{year}.html;;m`
尾部常带 `;;` 附加标记（jar 模式开关，引擎忽略之）；`;;ak`/`;;m0` 等是简写站专属开关。

**要点**：
- 这类站 `{cateId}` 常在**第一段**（如 `/html/tv…`），分类值就是路径词（`tv`/`movie`），照抄，别硬凑数字。
- 分页与首页 URL 不同时（首页无 page 段），笔记做法：`[英中括号]` 标注或直接按 分类url 只写分页式。

**默认字段** = template.go「短剧/路径式」项（与 §1 备选链近似，module 皮肤优先）。

---

## 四、路径式泛型 `{cateId}` 家族（152 份 ≈ 40%）

**指纹**：`/video/lists/{cateId}/{catePg}.html`、`/playtype/{cateId}/{catePg}.html`、`/type/{slug}/{page}/` 等
——**结构完全自定义、无 CMS 特征**，占最大族。

**要点**：
- 这一族**没有可靠的通用默认**（数组/标题形态随站千变万化），简写只能靠 `href="&&"`/`title="&&"`/`src="&&"` 这类全局高频值兜底；其余字段必须实测样本后逐站填写。
- 判断是否真能简写：抓一页分类 HTML，若条目容器是 `<li>`/`<a>` 且带 `title=`/`href=`，大概率简写即中；条目是 `<article>`/自定义 div 或懒加载 `data-src` 占位多，就老实全字段手写。
- 英文 slug 分类（ffv1.com 型：`/type/{slug}/{page}/`）要确认引擎支持非数字分类 ID（guoapp3 已放行 `categoryIDPattern`）。

## 五、纯 JSON 接口家族（笔记 item 7 `j:` 模式；实测 1 份完整 + MacCMS API 若干）

**指纹**：分类url 返回 `Content-Type: application/json`；或页面里嵌 JSON（`var player_aaaa={…}`）。

**写法**（SVPI 型全 JSON 站为标本）：
```json
{
  "分类url": "https://host/api/new?channeid={cateId}&page={catePg}",
  "分类": "短剧$1",
  "二次截取": "j:data.list",
  "数组": "j:list",
  "标题": "j:title",
  "图片": "j:coverUrl",
  "链接": "https://host/book/+j:shortId",
  "跳转播放链接": "j:data.urls[0].cdnUrl",
  "线路数组": "j:data.seriesInfo",
  "线路标题": "SVIP短剧"
}
```
- `二次截取=j:data.list` 缩小后，`数组=j:list` 是在缩小范围**再**找 `list` 键；找不到就把缩小结果当数组本身迭代（引擎两种都支持）。
- 下标 **0-based**（`urls[0]`）；`[1,]` 跳过前一个；json 模式内字面段用单引号 `'/play/'+j:id+'-1.html'`。
- 固定文案字段（`线路标题`）不写 `&&` 即为字面量。
- MacCMS API 站（`?ac=videolist`）返回 `vod_name/vod_pic/vod_play_url` 结构，引擎有 JSON 兜底，规则里用 `"vod_name":"&&"` 式截取或直接 j: 路径。

## 六、直播 / txt 型（简写外的 no_cateurl 群，40 份）

笔记范例（live.txt）：`主页url` 指 txt 文件、`直接播放":"1"`、`链接前缀:"http"`、
`数组":"INF:&&EXT"`、`副标题":"group-title=\"&&\""`，分类靠「指定截取」分块：
`"二次截取":"央视--\\#\\#央视&&\\#\\#||卫视--\\#\\#卫视&&\\#\\#"`（`\\#` 转义 `#`）。
- 无分类单页想按分类展示：地址尾拼 `?{cateId}`，再给各分类指定截取。
- 短视频/直播聚合：`"短视频":"1"` 拉整页直接播放。

## 七、字段级通用默认（跨家族）

| 字段 | 默认/惯例 |
|---|---|
| 编码 | UTF-8；老站 `gb2312`（看 `<meta charset>`） |
| 请求头 | `User-Agent$MOBILE_UA`；桌面站可省；带 Cookie 写 `User-Agent$…#Cookie$…`（$ 分隔键值、# 分隔多条头） |
| 播放请求头 | 播放 CDN 校验 Referer 时单写（样例：修罗 `;;d0` 尾部标记形态） |
| 起始页 | 默认 1；站从 0 或 2 起时改 |
| 倒序 | 一般自动；显式 `"倒序":"1"` 强制 |
| 免嗅/强制解析/图片代理 | 默认 0；嗅探失败调 1 |
| 筛选 | 不填时按 分类url 占位符自动生成；可填外部 JSON 地址或直接贴 `{…}` |
| 年份 | 默认近 15 年；`起始年-终止年` 可改 |
| 排序 | 默认 `$time`/`$hits` 英文键 |
| 调试 | `"调试":"1"` 让 jar 弹出截到的链接（仅真机 jar 有效） |

## 八、写源决策树（快速套用模板的流程）

```
1. 抓首页 → Content-Type 是 JSON？ → §5 j: 模式全家
2. 分类 URL 命中哪个家族？（§1/§2/§3/§4 指纹）
   ├─ §1/§2/§3 → 直接简写：分类url+分类，缺什么补什么（引擎模板已带 §1 备选链）
   ├─ §4 → 抓分类页看条目是否 <li>/<a>+title/href，是→半简写，否→全手写
   └─ 直播 txt/m3u → §6
3. 播放页找直链：优先 var player_aaaa / url:'…' / <video src>；
   MacCMS 站可省 跳转播放链接（引擎 PlayerURL 兜底更稳，见 55yss/6789ysw 实战教训）
4. 写完必须六步实测：parse → catalog → paging → search → detail → play(#EXTM3U)
```
